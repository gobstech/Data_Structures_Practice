# Data Structures — Semester Practice

This repository was created to share my roadmap through this semester's Data Structures subject. Here I'll be uploading the exercises and projects developed throughout the course.

## Structure

Content is organized into numbered folders, one per topic, in the order they're covered in class:

- `1-introduction/` — first contact with C: variables, input/output, and basic arithmetic.
- `2-if-else/` — conditional logic exercises.

New topic folders will be added as the semester progresses (e.g. loops, arrays, functions, pointers, linked lists, and other data structures).

Each topic folder contains one subfolder per exercise, named after what it solves (e.g. `area-of-triangle`, `even-or-odd`). Inside each exercise folder:

- `main.c` — the C source code for that exercise.
- `output` — the compiled executable/output for that exercise.

## Language

Exercises are written in C.
